# grindhive

Grind timestamps and hive durations for scripts and CI receipts.

**Site:** https://theworker02.github.io/grindhive/

## Install / run

```bash
git clone https://github.com/theworker02/grindhive.git
cd grindhive
node src/cli.js
node --test
```
